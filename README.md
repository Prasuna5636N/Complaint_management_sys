A full-stack web application for managing and tracking complaints efficiently. Built with the MERN stack (MongoDB, Express.js, React.js, Node.js), this system provides a seamless interface for users to submit complaints and for administrators to manage them with real-time status tracking.


## Run

1. Backend
```bash
cd backend
npm install
npm run dev      # Starts on http://localhost:5000
```
---
2. Frontend
```bash
cd frontend
npm install
npm start        # Starts on http://localhost:3000
```
